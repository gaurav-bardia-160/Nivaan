1. PROJECT IN ONE LINE
============================================================
GovBank Assistant is a source-grounded AI helper that explains government, tax, banking, and legal procedures/documents in simple language, while masking sensitive user data and showing honest sources, dates, warnings, and limitations.

============================================================
2. REAL GOAL OF THE PROJECT
============================================================
The project is linked to the communication theme because it solves the communication gap between official institutions and ordinary citizens.

The user problem:
- Government forms are hard to understand.
- Tax steps are confusing.
- Bank/loan documents hide important terms in complex wording.
- Legal notices scare people, and people may miss deadlines.
- People may depend on agents or middlemen because official communication is not simple.

The solution:
- User asks a question or uploads a supported document.
- System masks sensitive data.
- System finds a matching verified guide from the knowledge base.
- System explains the procedure in a fixed, simple answer format.
- System flags risky clauses and deadlines.
- System shows source link, last verified date, confidence, and disclaimer.

Important boundary:
This project must not act like a lawyer, CA, bank officer, or government authority. It should explain, guide, flag, and cite. It should not make final decisions for the user.

6. HOW THE SYSTEM WORKS RIGHT NOW
============================================================

Typed question flow:
1. User types a question in frontend.
2. app.js sends POST /api/ask.
3. main.py validates AskRequest.
4. pipeline.py combines text.
5. guardrails.py masks sensitive values.
6. agent.py routes category.
7. retrieval.py finds matching entry in knowledge_base.json.
8. explainer.py builds structured Answer.
9. translate_voice.py returns English or adds non-English limitation warning.
10. frontend renders answer.

File upload flow:
1. User uploads supported file.
2. app.js sends POST /api/ask-file multipart request.
3. main.py reads file bytes without storing on disk.
4. ocr.py extracts text if supported.
5. main.py creates AskRequest with document_text.
6. pipeline.py masks text.
7. retrieval.py finds guide.
8. guardrails.py adds document risk flags.
9. explainer.py returns Answer.
10. frontend renders checklist, warnings, masked items, source, date.

Unsupported file flow:
1. User uploads image or scanned PDF.
2. ocr.py rejects with clear OCRExtractionError.
3. main.py returns proper HTTP error.
4. Frontend should show user-friendly message.
