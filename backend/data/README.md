# Data folders

- `sources.json`: official source list grouped by tax, banking, schemes, and legal.
- `raw/`: future downloaded pages and PDFs from whitelisted sources.
- `cleaned_chunks/`: future cleaned text chunks with source metadata.
- `structured_entries/`: future AI-structured drafts, not trusted yet.
- `pending_review/`: future entries waiting for human verification.
- `verified_entries/`: future human-verified entries used for answers.
- `vector_index/`: future searchable embedding index.
- `knowledge_base.json`: small manually curated library for the earliest version.

Do not place real user documents here.
