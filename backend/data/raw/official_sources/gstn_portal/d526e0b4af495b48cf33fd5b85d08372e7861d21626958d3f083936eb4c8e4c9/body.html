Manual > Return Compliance for the Form DRC-01B Part B

If there is a difference between the liability declared in GSTR-1/IFF and the amount paid through Form GSTR-3B/3BQ that exceeds a pre-defined limit, you will receive an intimation in Form GST DRC-01B. In such cases, it is mandatory to file Form GST DRC-01B Part B to provide the necessary details and reconcile the difference.


Note: If you do not file response of Form GST DRC-01B Part B, then you will not be able to file GSTR-1/IFF for the subsequent Tax period. 

How can I file Form GST DRC-01B PART B?

To file the Form GST DRC-01B Part B, please follow the steps below:
1.    Access the GST portal by visiting www.gst.gov.in. The GST home page will be displayed.
2.    Login to the GST Portal using your valid credentials.
3.    Navigate to Services > Returns > Return Compliance option. Alternatively, you can directly click on the Return Compliance link available on the dashboard.

 

By following these steps, you will be able to access the necessary section to file Form GST DRC-01B Part B on the GST portal.

 


4. The Return Compliance page is displayed. In the Liability Mismatch (DRC-01B) tile, click the VIEW button.

 

 

 

5. The Liability Mismatch (DRC-01B) page is displayed. The pending records will be displayed. Click the Reference number hyperlink.

 

 

Note: Alternatively, you can click any one option from Reference number, Return period or Status to search for the intimation Form GST DRC-01B which is issued to you.

 

Case 1: If you click the Reference number option, then enter the ARN and click the SEARCH button. You will get all the completed and pending records list. 
If the status for the record is pending, then you can file the Form GST DRC-01B.

 

 

Case 2: If you click the Return Period option, then you need to select the Financial Year for which you need to file Form GST DRC-01B and Return Period from the drop-down list. Click the SEARCH button. You will get the completed and pending records list. 

 

If the status for the record is pending, then you can file the Form GST DRC-01B. 

 

Note: Return Period option will get enabled only after you select the Financial Year.

 



 

Case 3: If you click the Status option, then you need to select the status Pending or Completed from the drop-down list and click the SEARCH button. 


If you select Pending status, then pending records will be displayed. For the Pending record, you can file the Form GST DRC-01B.


If you select the Completed records, then the completed records will be displayed.

 

 

6. The Liability Mismatch (DRC-01B) details page with PART-A and PART-B will be displayed. PART-A will display the Intimation of Difference in Liability Reported in Statement of Outward Supplies and that Reported in Return. 

 

In PART-B Reply by Taxpayer in Respect of the Intimation of Difference in Liability, there are two sub-parts. In part 1, you can provide the ARN of the payment which is made via Form GST DRC-03 for the period for which Form GST DRC-01B has been issued to you.

 

You can also make the payment for the Difference in Liability Reported by clicking the CLICK HERE FOR DRC-03 button. In part 2, you can select the Reason for the Difference in Liability Reported and provide further explanations in the text box.
 


Note 1: You can click the DOWNLOAD DRC-01B PART-A button to download the Form GST DRC-01B PART A form.

 


Note 2: The system generated PDF for Form GST DRC-01B PART A will be downloaded.

 

 

Note 3: Click the DOWNLOAD DRC-01B button. A system-generated draft form will be downloaded into your system as displayed. Check the system-generated draft form carefully to rule out any discrepancy.

 

7. In PART-B, enter the ARN of Form GST DRC-03 through which payment towards discrepancy communicated in Form GST DRC-01B PART A was made  and click the VALIDATE button.

 

 

Note 1: If you have entered the incorrect ARN, then an error message will be displayed.



If you are getting this error message, then you need to check the following points:


•    ARN is valid only, if this is the ARN for same Form GST DRC-03 and of the same GSTIN.
•    The Form GST DRC-03 should have been filed on or after the date on which Form GST DRC-01B part A was issued.
•    The Cause of payment is Liability mismatch – GSTR-1 to GSTR-3B.
•    The overall tax period pertains to the period for which the Form GST DRC-01B Part A has been issued.

        o    For Monthly, it is of the same period, both From and To.

        o    For Quarterly, it is of at least one month of the quarter.

 

Note 2: You will be able to file part B of Form GST DRC-01B by providing response in either sub part 1 or 2 or in both. It is not mandatory to enter ARN of Form GST DRC-03.

 

Note 3: If you click the CLICK HERE FOR DRC-03 button, then you will be navigated to the Form GST DRC-03 page for making the payment, in case you need to pay any amount. 

 

8. The summary of the payment details that has been paid towards the difference amount through Form GST DRC-03 will be displayed.

 


9. Select and explain the reason for the difference in the liability, in the space provided.
Note: In PART-B, you can either validate the ARN of Form GST DRC-03 or provide the reason for the Difference in Liability. You can also provide both, the ARN of Form GST DRC-03 and Difference of Liability.

 

 

Note 1: You can select any reason out of the four options given. If your reason is not specified, then you can select any other reasons and explain the reason in the space provided. You can use up to 500 characters to explain your reason.

 

Note 2: If you have selected the reason for the difference in liability, but not explained the reason in the space provided then, an error message will pop-up.

 

 

Note 3: Click the BACK button to go to the previous page.

 

10. Click the SAVE button. Select the declaration Checkbox. Select the Name of Authorized signatory from the drop-down list and enter the Place. Click the FILE GST DRC-01B button.

 

 

Note 1: The checkbox for selecting the declaration will be enabled only after clicking the Save button.

 

A success message will also be displayed at the top of the screen, upon successfully saving the details.

 


 
Note 2: The FILE GST DRC-01B button will be enabled only after you select the Name of Authorized signatory and entered the Place. Designation/Status and Date will be auto populated.


Note 3: Click the DOWNLOAD DRC-01B button. A system-generated draft form will be downloaded into your system as displayed. Check the system-generated draft form carefully to rule out any discrepancy.

 

 

11. A Warning message will pop-up. Click the PROCEED button.
 

 

Note: If you want to make changes in the PART-B of Form GST DRC-01B, then click the CANCEL button.

 

12. Click the FILE DRC-01B WITH EVC button.
Note: You can also select FILE DRC-01B WITH DSC.

 

 

13. Enter the OTP sent on email and mobile number of the Primary Authorized Signatory registered at the GST Portal and click the VERIFY button.

 

 

14. A Success message will pop-up. Click the OK button to complete the process.

 

 

Note: You can check the status of the Form GST DRC-01B as Completed from the Status option. 

 

 

15. Click the Reference number hyperlink.

 


16. The completed form will be displayed. Click the DOWNLOAD DRC-01B button to download the final PDF of Form GST DRC-01B. 

 


 Note: A system-generated final PDF will be downloaded into your system as displayed.
