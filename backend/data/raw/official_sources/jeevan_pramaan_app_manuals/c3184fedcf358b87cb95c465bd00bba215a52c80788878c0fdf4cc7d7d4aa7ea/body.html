Download Application
For Windows and Android/IOS Operating System
The client software is intended to be used only for Pensioner's life certificate registration.
Usage of the application for any other purpose is prohibited.

Android


  1. Android 10.0 or above (Un-rooted device).
  2. Download and install Jeevan Pramman App from Play Store.
  3. Download and install AadhaarFaceRd from Play Store for Face Authentication.
  4. Download and install Bio-Metric device RD service from Play Store for Finger Print/Iris Authentication.


IOS


  1. IOS 14.0 or above (Un-rooted device).
  2. Download and install Jeevan Pramman App from App Store.
  3. Download and install AadhaarFaceRd from App Store for Face Authentication.

Note: The Jeevan Pramaan Face Authentication (Android/iOS) does not require a biometric device, as it uses the mobile phone's camera to capture the face. The Android version of the app can also be used with an external biometric device if needed. iOS devices currently support Face Authentication only.

** In case you require support please contact our help desk at jeevanpramaan[at]gov[dot]in.

Windows



  1. Microsoft .Net Framework version 4 - Full (or) Higher
  2. Microsoft Visual C++ 2010 Re distributable Package for Windows machine.
  3. Jeevan Pramaan client software (Windows) will require a biometric fingerprint/ iris scanner device.
