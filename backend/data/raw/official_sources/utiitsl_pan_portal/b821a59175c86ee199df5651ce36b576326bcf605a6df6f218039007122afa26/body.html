1. Applicant's may apply for PAN card using paperless feature (without manual submission) using Aadhaar based e-KYC services.
2. The user has to select the Digital (e-KYC) application mode, applicant status along with the option of 'e-PAN only' or 'e-PAN with physical PAN Card' on the first screen.
2. On successful submission, a reference number will be generated.
3. The reference number has to be retained for interim use till the Application number gets generated.
4. Once the payment is successful then the Aadhaar will be authenticated on real time basis from UIDAI server.
5. In case of mismatch in Demographic Aadhaar authentication, then the application will be rejected and the payment will be refunded by end of day through the system itself.
6. On successful Aadhaar authentication, the applicant's data will be fetched as per UIDAI record through mobile OTP authentication or biometric authentication as per user's choice. There cannot be any change made in the residential address and even in the communication address option as per e-KYC norms. If the Applicant's profession is 'salaried' then providing of office name and address is mandatory.
7. In case e-KYC is not successful and is found to be failure due to any technical reason then the payment will be refunded by end of day through the system itself.
8. On successful completion of application immediately after generation of application no., Aadhaar based e-Sign service will be called through the system for electronic/digitally signing of the application.
9. If e-Sign is not completed instantly or on the same day, the case will be moved to 'objections list' for electronic/digitally signing later.
10. Due to any other interim technical issue with e-Sign, the users can check the cases pending for e-Sign under 'Pending for e-Sign option' menu.
11. If the application with e-Sign is successfully completed, the user need not send physical printed copy to UTIITSL unless it is demanded for.

1. Applicants may apply for PAN card using paperless feature (without manual submission) of signing using DSC Digital Signature Certificate (Class II / Class III DSC).

2. After complete filling of the application form the applicant has to upload the supporting documents in PDF format and Picture, Signature files in JPEG/JPG format by     selecting from local system or from the Digilocker as per required specification.

3. On complete submission of the application, it will redirect to payment gateway for payment.

4. If the payment transaction failed due to any unknown reasons, applicant may again initiate for payment using the option "Regenerate online PAN application".

5. After successful payment, The PAN application in PDF format having photo, signature and supporting documents at appropriate places will be shown to the      applicant for Download and PAN applicant will apply digital signature on the downloaded PAN Form.

6. Once digitally signed, Applicant will upload the signed PDF.

7. DSC of the applicant and Validity of the DSC will be validated.

8. DSC name verification may be matched with different filled values from the application based on the names provided in different fields (for example applicant card     name / in case of minor applicant assessee name / in case of non individual Verifier name). However only exact matching is allowed.

9. After successful verification of DSC, Application will be moved to processing zone.

10. Please note the user does not need to send any files / printouts if unless UTIITSL demands for any clarification.
