# Backend modules

Planned online-serving modules:

- `ocr.py`: read future PDFs and images into text.
- `privacy.py`: mask sensitive values before external AI use.
- `router.py`: detect question or document and broad area.
- `retrieval.py`: retrieve verified chunks or return no match.
- `flagger.py`: detect deadlines and risky clauses.
- `explainer.py`: create fixed-shape answers from retrieved material.
- `tools.py`: future official-site checks.
- `agent.py`: future decision loop and follow-up memory.
- `translate_voice.py`: future translation and audio.

Build these one by one. Do not connect all at once.
